# SCA Data Platform

Python-first analytics platform for the Saudi Contractors Authority. Phase 1 provides a single-admin workspace with dataset metadata, aggregated membership indicators, interactive visualizations, and configurable transformation triggers.

## Technology

- Python
- Streamlit
- Pandas
- Plotly

## Run locally

```bash
python -m venv .venv
```

Activate the environment, then install and run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Development phases

1. Single-admin dashboard and interaction model.
2. User roles, dedicated pages, and identity/access management.
3. Expanded transformation rules, visual configuration, and integrations.

## Current status

The dashboard uses representative membership data. Real data connections and formal transformation rules will be added after the Phase 1 interface is approved.
